# Decisioni architetturali dello studio

Nessuna decisione esercitata dall’utente ancora registrata. Le scelte organizzative iniziali sono nel [piano generale](../PIANO-GENERALE.md).

Durante i casi usare il modello [DECISIONE.md](../../templates/DECISIONE.md), collegando ogni decisione a obiettivi e fonti. Conservare alternative, motivazioni, condizioni che cambiano la scelta e verifiche. Non copiare soluzioni dei casi MicrosoftLearning nel repository.
