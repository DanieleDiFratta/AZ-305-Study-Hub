# Materiali e originali

La biblioteca corrente usa collegamenti alle fonti ufficiali; nessun articolo, diagramma o soluzione originale Microsoft viene distribuito qui. I metadati sono in [data/catalog.json](../data/catalog.json).

Eventuali file scaricati per uso personale durante le sessioni devono conservare provenienza, data e condizioni di utilizzo. Non aggiungere al repository copie di materiale di terzi senza averne verificato i diritti. Non aggiungere exam dumps o esportazioni di assessment.

La cache HTML di ricerca è in `.cache/`, ignorata da Git e non necessaria per consultare la biblioteca o eseguire i controlli locali. Gli elaborati originali delle future sessioni saranno in `studio/`, distinti dai materiali delle fonti.
